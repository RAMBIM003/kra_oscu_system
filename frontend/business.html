PAYMENTS

Connect M-Pesa

Forward payment confirmation SMS into this platform.

M-Pesa has no API for payments you send out, so outgoing payments are captured from the confirmation SMS instead. Install an SMS-forwarding app on the phone that receives M-Pesa messages and point it at the endpoint below.

POST http://localhost:5000/api/payments/webhook
Replace localhost with your server's public address once deployed - a phone cannot reach localhost.
Content-Type: application/json
x-webhook-secret: <SMS_WEBHOOK_SECRET from .env>
{
  "businessId": <business id>,
  "message": "<raw M-Pesa SMS text>"
}
The platform parses the receipt number, amount, recipient and time from the raw SMS text automatically.
